# Logo

The Holdout logo: the app icon's crowd and H, with the name in Roboto Flex 300, outlined. See **Logo** under Iconography in the brand book for clear space, minimum sizes and what never to do.

- `holdout-logo-horizontal.svg`: the default lockup, on `#000000`. Members `#FFFFFF`, the H `#80ECFF`, the name `#FFFFFF`. Clear space of two grid steps is inside the file.
- `holdout-logo-horizontal-1188.png`: the same at 1188 px wide, for decks and documents that won't take SVG.
- `holdout-logo-stacked.svg`, `holdout-logo-stacked-774.png`: the mark above the name, for square spaces.
- `holdout-wordmark.svg`: the name alone, white on black, for places where the icon already sits beside it.
- `holdout-mark.svg`: the mark alone with its clear space, no tile.
- `holdout-logo-horizontal-mono-black.svg`: one ink `#000000` on a transparent ground, for light pages and print. The H is the bold themed-icon geometry, without the crowd.

The colour files are only for black grounds. Everything is outlined: no font is needed to open them.
