# Roster row

One member of a Holdout, by shortened address only.

**Use for:** the roster on the **Standing** tab and, in Phase 2, the leaderboards. Members still standing come first, then forfeited members ordered by days lasted.

**Anatomy:** `size-button` tall, `hairline` dividers. The address uses `amount` at 16px (`ABcd…wxYZ`, `Format.short`). Days sit right-aligned in mono, `success` with a ✓ while standing. A forfeited member's address drops to `text-tertiary` with *lasted N days*. A scripted member carries a `◇ SCRIPTED` label chip on every roster.

**Never:** show a stake, prize or payout amount on a roster, ever. Rank by discipline, never by money.
