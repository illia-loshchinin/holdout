`docs/design/` mirrors the artifact and is never edited by hand. To refresh it, follow
`.claude/skills/holdout-ui/references/sync.md`.

Files here:

- `README.md` — the brand book (principles, voice, naming, visual foundations, iconography).
- `lab.md` — the Holdout Lab section: the LAB marker, the icon exception, the words and the components Lab adds.
- `launch.md` — how the brand shows up outside the app: store listing, website and social, the pitch deck and demo video, and the disclosures.
- `tokens.json` — every token, the source the Kotlin theme is checked against.
- `components/<Comp>/README.md` — guidelines per component; `preview.html` — its HTML reference.
- `components/bundle.css` — the `ho-*` HTML reference implementation.
- `assets/app-icon/README.md`, `assets/logo/README.md` — the app icon set and the logo lockups (the image files stay in the artifact).
- `tokens.css`, `gallery.html` — generated by `python scripts/design-book.py build`; do not edit.

Not mirrored: the artifact's generated `api/` cards, `tokens.css` and `manifest.json` (at version
1791530923-cf8b its generated files still show the old `celebration` value `#c80c9c`; `tokens.json`
has `#9945ff`, which matches `Color.kt`).
